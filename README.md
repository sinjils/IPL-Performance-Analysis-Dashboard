# IPL Performance Analysis Dashboard

Interactive IPL Performance Analysis Dashboard analyzing IPL seasons from **2007 to 2014** using **SQL** and **Power BI**.

## Tools Used
- SQL
- Power BI
- CSV

## Dashboard Pages
- IPL Overview
- Team Performance Analysis
- Batting Analysis
- Bowling Analysis

## Key Insights
- Team Win Percentage
- Team Total Runs
- Top 10 Batters by Runs
- Top 10 Batters by Fours
- Top 10 Batters by Sixes
- Top 10 Bowlers by Wickets
- Top 10 Bowlers by Economy Rate
